# Jatlas

일본 여행 가이드의 전체 정적 웹사이트 소스입니다.

- 내보낸 버전: 27 (2026-09-29)
- 기준 커밋: `025f6528043034b5ad21d9bf87128f83a74ba4db`
- 원래 구현: HTML / CSS / JavaScript, Leaflet
- npm 패키지 설치 및 빌드 불필요. 원래 프로젝트에 package.json은 없습니다.

## 실행

Python 3가 설치된 컴퓨터에서 이 README가 있는 폴더를 열고 실행합니다.

```sh
python -m http.server 8000 --directory dist
```

Windows에서 python 명령이 없다면 `py -m http.server 8000 --directory dist`를 사용합니다.
브라우저에서 http://localhost:8000 을 엽니다. 파일을 더블클릭하는 방식보다 HTTP 서버 실행을 권장합니다.
다른 정적 웹 서버를 사용한다면 웹 루트를 `dist/`로 지정하면 됩니다.

## 프로젝트 구조

- `dist/index.html`: 사이트 진입점
- `dist/*.css`, `dist/*.js`: 화면, 탐색, 번역, 장소·음식·행사·일정 데이터와 기능의 실제 소스
- `dist/images/`: 로고·관광지·음식 사진, 출처 데이터
- `dist/boundaries/`: 도도부현별 시구정촌 경계 데이터 및 라이선스
- `dist/vendor/`: 로컬 지도 라이브러리와 관련 파일
- `sources/`: 관광 정보·사진·지도 출처와 조사 JSON
- `scripts/`: 기존 지도·지명 자료 가공 스크립트 (사이트 실행에는 필요 없음)
- `.openai/hosting.json`: 기존 호스팅 설정. 다른 호스팅에서 실행하는 데 필요하지 않습니다.
- `EXPORT-MANIFEST.json`: ZIP에 포함한 파일의 크기·SHA-256 검증 목록

## GitHub 업로드

압축을 해제하고 `Jatlas-v27` 폴더 **안의 내용 전체**를 저장소 루트에 업로드합니다.
`dist/`, `sources/`, `scripts/` 등의 폴더 구조를 유지하세요.
GitHub 저장소에 소스를 올리는 것과 웹사이트를 배포하는 것은 별도입니다.
정적 호스팅으로 배포할 때는 빌드 명령 없이 `dist`를 공개 폴더로 지정하세요.
이 ZIP은 GitHub 계정에 직접 업로드하거나 기존 사이트를 변경하지 않습니다.

## 인터넷 연결과 데이터 저장

- 상세 지도는 Google Maps iframe을 사용하므로 인터넷 연결이 필요합니다. Google의 지도 서비스 자체는 ZIP에 포함할 수 없습니다.
- 공식 관광 안내·사진 출처·길찾기 링크도 인터넷 연결이 필요합니다.
- 사이트에서 사용하는 로컬 이미지, 경계 데이터, JS/CSS 라이브러리를 포함했습니다.
- 기존 야마나시 사진의 외부 이미지 주소는 내보낸 복사본에서 로컬 파일로 치환했습니다. 원본 URL은 `sources/export-image-manifest.json`에 보존했습니다. 원래 게시된 사이트에는 변경을 가하지 않았습니다.
- 내 계획·관심 장소·언어 설정은 브라우저 localStorage에 저장됩니다. 사용자가 기존 사이트에서 저장한 개인 일정은 소스에 포함되지 않습니다. 호스팅 주소가 바뀌면 기존 사이트의 계획 내보내기/가져오기 기능으로 옮기세요.
- API 키, 비밀번호, Git 인증정보, Git 이력은 포함하지 않았습니다.

## 콘텐츠와 라이선스

사진과 지도 데이터의 출처·이용 조건은 사이트 하단 출처 목록과 각 출처/라이선스 파일을 유지하세요.
소스 전체에 새로운 포괄적 오픈소스 라이선스를 부여한 것은 아닙니다. 제3자 자료는 각각의 이용 조건을 따릅니다.
사진이 아직 등록되지 않은 관광지·음식은 원래 배포본과 동일하게 사진이 없습니다. 이는 ZIP 파일 누락이 아닙니다.
